# Deploy to Vercel (Fast & Free - Recommended)

Vercel is the easiest free way to host your portfolio with unlimited bandwidth.

## Step 1: Install Vercel CLI

```bash
npm install -g vercel
```

## Step 2: Deploy

```bash
cd /Users/fardeenkhan/Desktop/portfolio-assets
vercel
```

It will ask a few questions:
- **Set up and deploy?** → yes
- **Scope** → your account
- **Project name** → `fardeen-portfolio`
- **Build command** → press Enter (leave blank)
- **Output directory** → press Enter (leave blank, use `.`)

Your site will be live in 30 seconds! 

You'll get a URL like: `https://fardeen-portfolio.vercel.app/`

---

## Alternative: GitHub Pages (Most Popular)

If you prefer GitHub Pages:

1. Go to github.com and create an account (if you don't have one)
2. Create a new public repository named `portfolio`
3. Upload all files from `portfolio-assets` folder to the repository
4. Go to Settings → Pages → select `main` branch
5. Your site goes live at `https://yourusername.github.io/portfolio/`

Done! No size limits, no compression needed, all quality preserved.
